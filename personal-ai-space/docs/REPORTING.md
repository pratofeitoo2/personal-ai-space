## Custom Report Query

**Type**: User-requested analysis  
**Format**: JSON  
**Response Time**: < 5 seconds

### Example: "How much time did I spend on projects this week?"

```json
{
  "query": "time_on_projects_week",
  "period": "2026-04-29 to 2026-05-05",
  "results": {
    "total_hours": 18.5,
    "projects": [
      {
        "name": "Personal AI Powerhouse",
        "hours": 12.3,
        "tasks_completed": 8,
        "productivity": "high"
      },
      {
        "name": "Knowledge Management",
        "hours": 4.2,
        "tasks_completed": 3,
        "productivity": "medium"
      },
      {
        "name": "Other",
        "hours": 2.0,
        "tasks_completed": 1,
        "productivity": "low"
      }
    ],
    "comparison": {
      "vs_last_week": "+15%",
      "vs_monthly_avg": "+8%"
    }
  }
}
```

## Report Distribution

### Delivery Channels
- Email (daily digest, weekly review, monthly)
- Dashboard (real-time metrics)
- Files (JSON for integration, PDF for sharing)
- Notifications (alerts for anomalies)

### Storage
- All reports archived in `reports/` subdirectory
- Organized by date and type
- Queryable via report-generator agent
