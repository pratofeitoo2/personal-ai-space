=============================================================================
ALGORITHMS
=============================================================================

Jaccard Similarity (Semantic Deduplication)
   Formula: |intersection| / |union| on token sets
   Threshold: ≥0.7 (70% similar = duplicate)
   Complexity: O(n+m) per comparison
   Use Case: Detect lessons expressing same idea with different wording

Exact Match Deduplication (Fast Path)
   Facts: O(1) key lookup via Set
   Lessons: Case-insensitive text comparison
   Use Case: Fast first-pass duplicate detection

Confidence Filtering (Quality Control)
   Threshold: ≥0.8 (only high-confidence facts stored)
   Reasoning: Prevent noise in memory
   Tracked: factsRejectedByConfidence in results

Category Prefixes (Organization)
   pref.*       - User preferences
   project.*    - Project-specific patterns
   tool.*       - Tool preferences
   user.*       - User identity/metadata
   Use Case: Organize and filter knowledge by category
