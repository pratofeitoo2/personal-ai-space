# 02 - Self/

## Responsibility
Digital twin — the system's evolving model of the user. Stores personal profile, goals, habits, personality traits, relationships, and inferred behavioral patterns. Consumed by agents for context-aware personalization.

## Data Model

| File | Format | Responsibility |
|------|--------|---------------|
| `profile.json` | JSON | Master profile — name, timezone, work style, goals, constraints, preferences |
| `traits/inferred_personality.json` | JSON | Inferred personality patterns — traits, communication style, work rhythm, decision patterns |
| `needs/current_needs.json` | JSON | Active needs and priorities — what the user currently needs help with |
| `habits/tracking.csv` | CSV | Habit tracking data — date, habit name, completion status, notes |

## Subdirectory Map

| Directory | Contents |
|-----------|---------|
| `goals/` | 90+ career, study, and life planning files (markdown, PDFs, canvases) |
| `habits/` | Habit tracking data (`tracking.csv`) |
| `needs/` | Current needs and priorities JSON |
| `traits/` | Inferred personality and behavioral traits |
| `behaviors/` | Behavior analysis data (generated by behavior_observer agent) |
| `insights/` | AI-generated learning and insights (generated by insight_generator agent) |
| `relationships/` | People network — 6 relationship files (Liz, Luan, Mallu, Ravi, Tamara, PF Rezende) + People.base template |

## Integration Points
- **Consumed by**: `context_manager` agent (loads profile for session context), all other agents
- **Database mirror**: `db/self.db` with schema in `db/schema_self.sql` (9 tables for profile, habits, traits, needs, goals, relationships)
- **MCP sync**: Profile facts synced to MCP memory via `mcp_bridge.sync_profile_facts()`
